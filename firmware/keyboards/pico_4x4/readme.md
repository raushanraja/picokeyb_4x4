# Pico 4x4

A hand-wired 4x4 QMK matrix for the Raspberry Pi Pico.

* Keyboard Maintainer: community
* Hardware Supported: Raspberry Pi Pico (RP2040)
* Hardware Availability: DIY

Make example for this keyboard (after running the project setup script):

    qmk compile -kb pico_4x4 -km default

The default matrix uses GP9–GP12 as rows and GP1–GP4 as columns. See the project README for the wiring switch and UF2 upload instructions.
